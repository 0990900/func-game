# FP Draft Game v0.1

함수형 프로그래밍의 패턴을 설명보다 먼저 플레이로 경험하는 4인 드래프트 카드게임 프로토타입입니다. 현재 덱은 66장입니다.

## 실행

```bash
npm install
npm test
npm start
```

브라우저에서 `http://localhost:3107`을 엽니다. 다른 기기에서는 서버 머신의 LAN IP 또는 Tailscale IP와 3107 포트로 접속할 수 있습니다. 서버는 외부 인터페이스 접근을 위해 `0.0.0.0`에 바인딩됩니다.

다른 포트가 필요하면 `PORT=4000 npm start`처럼 실행 시 지정할 수 있습니다.

## 현재 포함

- WebSocket 실시간 방 생성/참가
- 최대 4자리, 빈 자리는 Bot으로 채움
- 3라운드 × 5픽 드래프트
- 게임 시작 시 무작위 자리 배정
- 순차 턴 진행, Pick마다 시작 플레이어 한 자리 순환
- 현재 턴, 플레이어 상태, 라운드 픽 진행 트랙
- 전체 60턴/개인 15픽 종료 진행도와 실시간 공개 점수
- 서버가 생성하는 공개 게임 이벤트 로그
- 내 턴 탭 제목, 화면 강조, 짧은 알림음
- 네 플레이어가 한 번씩 행동하면 왼쪽/오른쪽으로 손패 패스
- 공개 플레이 영역
- 중앙 시장 4장
- 현재 턴 플레이어만 시장 카드와 즉시 교환 가능
- Maybe / Either / List / Task 카드
- `*.operation`, `Container.*`, `*.*` 조커
- Utility 카드
- 타입클래스 조합 판정
- Claim +1점
- 비밀 목표
- 최종 점수

## 아직 없음

- 플레이어 간 Trade
- 재접속 토큰/세션 복구
- 턴 제한 시간과 시간 초과 Bot 대행
- 영속 저장소
- 관전자
- 방 비밀번호
- Claim 특수 능력
- 정교한 봇

## 설계 원칙

게임 규칙은 `src/game`에 두고 네트워크/UI와 분리합니다. 서버가 authoritative state를 소유하며 클라이언트에는 각 플레이어가 볼 수 있는 상태만 보냅니다.

Market Token과 시장 예약은 v0.1에 없습니다. 순차 턴이므로 시장 선택 충돌도 별도로 처리하지 않습니다.

## 규칙 해석과 남은 설계 이슈

- Claim의 “같은 조합은 한 번만”은 한 게임 전체 기준입니다. 새 조합을 만든 플레이어의 Claim 선택이 끝날 때까지 다음 턴은 시작되지 않습니다.
- 시장 교환은 손패 한 장을 시장에 놓고 해당 시장 카드 한 장을 플레이 영역에 추가하며, 일반 선택과 동일하게 한 턴을 소비합니다.
- 비밀 목표의 종류와 보너스(6~7점)는 현재 프로토타입에서 정의한 값입니다. 정식 밸런싱 전에 목표 조건과 점수를 플레이테스트해야 합니다.
- 게임 중 연결이 끊긴 사람의 턴 처리와 재접속 정책은 아직 없습니다. 현재는 해당 플레이어가 돌아오지 않으면 진행이 멈춥니다.
